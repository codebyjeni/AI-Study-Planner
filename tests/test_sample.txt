# AI-Based Study Planner – Test Cases

## Test Case 1 – Normal Input

### Sample Input

```text
Enter the number of subjects: 3
Enter available study hours per day: 5

Subject 1
Subject name: Python
Deadline: 2026-09-25
Difficulty: 3
Priority/Weight: 4

Subject 2
Subject name: Mathematics
Deadline: 2026-09-20
Difficulty: 5
Priority/Weight: 5

Subject 3
Subject name: Java
Deadline: 2026-09-30
Difficulty: 2
Priority/Weight: 3
```

### Expected Result

* Mathematics should receive the highest utility score.
* Python should receive the next priority.
* Java should receive a lower priority.
* A 7-day timetable should be generated.
* Higher-utility subjects should receive more study time.
